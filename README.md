# 🛒 AUCHAN E-Commerce Website

A modern e-commerce web application inspired by AUCHAN, featuring a customer-facing shopping interface and an admin dashboard for managing the online store.

## 🌐 Live Demo

[Visit AUCHAN E-Commerce Website](https://ecommerce-website-red-phi.vercel.app/)

---

## 📌 About The Project

**AUCHAN E-Commerce Website** is a front-end web development project designed to simulate an online shopping experience.

The application provides two main interfaces:

- **Customer Interface:** Allows users to explore the online store and interact with its shopping features.
- **Admin Dashboard:** Provides administrative tools for managing store data through CRUD operations and Drag & Drop functionality.

The project focuses on **JavaScript ES6+**, modular programming, dynamic DOM manipulation, and API integration.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/medlaksai/Auchan-E-Commerce-Website.git
```

### 2. Navigate to the project directory

```bash
cd Auchan-E-Commerce-Website
```

### 3. Run the project

Open the project using **Visual Studio Code** and launch `index.html` with the **Live Server** extension.

You can also access the administration interface by opening `admin.html`.

> **Note:** Using a local development server is recommended for projects that use JavaScript ES6 modules and Fetch API.
