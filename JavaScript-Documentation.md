# JavaScript Documentation 

## Function Predefined

- fetch() : Requests a file or URL and returns a Promise
- .then() / async-await : Runs code after the data is loaded 
- response.json() : converts the response into array/object
- localtStorage setItem / getItem / removeItem : saves and reads key-value data on a user's browser 
- Event delegration ( event.target , closest ()) : event listener to a parent element to handle events triggered by its child elements 
- dataset (data-id) : store custom values on an element 
- find() : search on an array and returns first matching element
- map() : creates a new array by transforming each element of the original array 
- filter() : creates a new aarray containing only the elements that match a specific condition 
- Number() : converts text to a number
- string : converts a value into string
- trim() : removes white spaces at the start and end of a string
- join() : combine elements into a signle string 
- Math.max() : returns the largest number from a set of values
- Date.now : generates an id based on current time
- form.reset() : clears all forn fileds 
- confirm() : shows an ok message or cancel 
- ES modules ( import / export ) : split code accross multi files 
- draggable , dragstart , dragover , drop. dataTransfer : native drag and drop
